Tailwind CSS Cheatsheet

Anatomía de una clase

Casi todas las utilidades siguen una misma estructura modular combinable de izquierda a derecha:

md: hover: bg - blue-600 / 90
1. Pantalla: desde 768px
2. Estado: al pasar cursor
3. Propiedad: fondo (bg)
4. Valor: azul tono 600
5. Opacidad: 90% visible

Símbolos y modificadores especiales

  • Guion inicial (-): Convierte medidas en negativas. Ej: -mt-4 (margin-top: -1rem).
  • Barra inclinada (/): Opacidad de color (0 a 100). Ej: bg-slate-900/50.
  • Exclamación (!): Fuerza !important. Ej: !mt-0 (v3) o mt-0! (v4).
  • Corchetes ([...]): Valor CSS arbitrario puntual. Ej: w-[340px], bg-[#1a2b3c].
PARTE 2

Ampliación por elementos

1. Layout, Display y Posicionamiento

display / position

Tipo de caja (display)

block, inline-block, inline, flex, inline-flex, grid, hidden (oculta elemento).

Posicionamiento (position)

  • static — Flujo normal por defecto.
  • relative — Referencia para hijos con absolute.
  • absolute — Posición libre respecto al padre relative.
  • fixed — Fijo respecto a la ventana del navegador.
  • sticky — Se pega al hacer scroll al llegar a un punto (ej. sticky top-0).

Coordenadas, capas y desbordamiento

inset-0 (pega a los 4 bordes), top-4, right-0, bottom-2, left-1/2, z-10, z-50, overflow-hidden, overflow-x-auto, aspect-video.

2. Flexbox y CSS Grid

flex / grid

Dirección y ajuste Flex

flex-row (fila), flex-col (columna), flex-wrap (salto de línea), flex-1 (ocupa espacio libre), shrink-0 (evita aplastarse), grow.

Alineación (Eje principal y cruzado)

  • Principal: justify-start, justify-center, justify-end, justify-between
  • Cruzado: items-start, items-center, items-end, items-stretch

Rejilla Grid y separación

grid-cols-1 hasta grid-cols-12 (columnas), col-span-5, col-span-full (extensión de hijo), gap-4, gap-x-8, gap-y-2.

3. Dimensiones y Espaciado

1 unidad = 4px
Escala base (0.25rem): 1=4px · 2=8px · 3=12px · 4=16px · 5=20px · 6=24px · 8=32px · 10=40px · 12=48px · 16=64px · 20=80px

Anchos (width)

w-full (100%), w-screen (100vw), w-fit (ajustado al texto), w-1/2 (50%), w-1/3 (33.3%).

Contenedores centrados y Altos

max-w-md (448px), max-w-3xl (768px), max-w-7xl (1280px) + mx-auto. Altos: h-full, h-screen, min-h-screen. Hijos: space-y-4.

4. Tipografía

text / font / leading

Escala de tamaño

text-xs (12px), text-sm (14px), text-base (16px), text-lg (18px), text-xl (20px), text-2xl (24px), text-3xl (30px), text-4xl (36px), text-5xl (48px).

Grosor (font-weight)

font-light (300), font-normal (400), font-medium (500), font-semibold (600), font-bold (700), font-extrabold (800).

Alineación, ritmo y recorte

text-left, text-center, text-right, uppercase, leading-tight, leading-relaxed, tracking-widest, truncate (corta con ...), line-clamp-2.

5. Fondos, Bordes y Efectos

bg / border / shadow

Fondos y degradados

bg-white, bg-transparent, bg-slate-900. Degradado: bg-gradient-to-r from-cyan-500 via-blue-500 to-indigo-600 (to-r, to-b, to-tr).

Bordes, divisores y radios

border (1px), border-2, border-dashed, divide-y divide-slate-200 (línea entre hijos). Radios: rounded (4px), rounded-lg (8px), rounded-xl (12px), rounded-2xl (16px), rounded-full.

Sombras y desenfoque

shadow-sm, shadow, shadow-md, shadow-lg, shadow-xl, opacity-75, backdrop-blur-md (efecto cristal).

6. Responsive, Estados y Animaciones

Mobile-First

Breakpoints (anchos mínimos)

sm: ≥640px · md: ≥768px · lg: ≥1024px · xl: ≥1280px · 2xl: ≥1536px

Estados e interacción padre-hijo (group)

hover:, focus:ring-2, active:, disabled:opacity-50, open: (para <details>). Padre con group o group/nombre → hijo con group-hover:translate-x-1 o group-open/nombre:rotate-45.

Transiciones y animaciones

transition-all, transition-colors, duration-200, duration-300, scale-105, rotate-45, -translate-y-1, animate-pulse, animate-spin, animate-bounce.
